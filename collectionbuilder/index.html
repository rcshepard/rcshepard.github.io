Marlow Harbor Historical Society · 1889–1953

Before the forecast, the harbor read the flags

For sixty-four years, anyone leaving Marlow Harbor checked four masts before they checked the sky. This collection gathers what survives of that service: the daybooks, the bunting, the instruments, and photographs of the men who hauled the halyards.

        About this demo

        This is a single self-contained HTML page that behaves like a small CollectionBuilder site: one metadata table drives a browse grid, subject index, timeline, station diagram, and item records.

        Everything here is invented. Marlow Harbor, the historical society, the signalmen, and all twenty records are fabricated for teaching purposes. Use them as placeholders, then replace them with your own metadata.

        Why flags instead of photographs

        A real CollectionBuilder site reads image files from an objects folder. This demo ships no image files, so each record displays a signal flag standing in for its digitized object, keyed to the letter in the record's accession sequence. The renderings are stylized versions of International Code of Signals flags.

        Putting it on GitHub Pages

        Save this file as index.html in a public repository, then open Settings → Pages and set the source to Deploy from a branch, branch main, folder /(root). The site appears at https://username.github.io/repository-name within a few minutes.

        Building the real thing without GitHub Desktop

        You do not need Git installed. Open the collectionbuilder-gh repository on GitHub, click Use this template, and edit _config.yml, the metadata CSV, and the objects folder entirely in the browser. GitHub Desktop is a convenience, not a requirement.

        Editing this page

        All twenty records live in one JavaScript array near the bottom of the file, marked const DATA. The field names match CollectionBuilder's: objectid, title, creator, date, description, subject, location, latitude, longitude, type, format, extent, rights, source. Subjects are separated with semicolons.
